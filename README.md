# Ramen Bowl Builder

A one-page web app for building a bowl of ramen from the bones up. Pick broth parts, aromatics, tare ingredients and toppings, and it recalculates the gelatin and flavor balance, salt, umami synergy and a combined shopping list as you go.

Everything runs in the browser from a single file, `index.html`, with no build step or server. Saved bowls and notes stay in each visitor's own browser.
